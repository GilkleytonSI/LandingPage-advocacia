# 📌 Site para Escritório de Advocacia

Este projeto consiste no desenvolvimento de um site institucional para um escritório de advocacia, com o objetivo de apresentar os serviços oferecidos, destacar a experiência da equipe e facilitar o contato com clientes em potencial.

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estruturação do conteúdo do site.
- **CSS3**: Estilização e responsividade do layout.
- **JavaScript (JS)**: Implementação de interatividade e funcionalidades dinâmicas.
- **Google Fonts**: Personalização da tipografia.
- **FontAwesome & Bootstrap Icons**: Uso de ícones para melhor identidade visual.
- **Google Tag Manager**: Integração para análise de desempenho e marketing.

## 🎯 Funcionalidades Principais

✅ Menu de navegação responsivo (desktop e mobile) <br>
✅ Seção com serviços oferecidos pelo escritório <br>
✅ Integração com WhatsApp para atendimento rápido <br>
✅ Incorporação de vídeo institucional do YouTube <br>
✅ Formulário de contato funcional via e-mail <br>
✅ Rodapé com informações de contato e redes sociais <br>

## 🛠️ Como Utilizar
1. Clone este repositório:  
   ```bash
   git clone https://github.com/GilkleytonSI/LandingPage-advocacia
   ```
2. Acesse o diretório do projeto:  
   ```bash
   cd LandingPage-advocacia
   ```
3. Abra o arquivo `index.html` no navegador.
